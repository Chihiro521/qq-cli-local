三步开始

INSTALLATION
01准备运行环境
Windows x64Node.js ≥ 22.5

先安装符合版本要求的 Node.js，然后打开 PowerShell。可用 node --version 查看版本。

使用 Classic PCQQ 加密数据库？展开查看额外依赖

需要 Classic PCQQ 9.7.25.29417 x86 正在运行并登录目标账号，以及 Python ≥ 3.10、frida 和 psutil。当前加密库适配范围锁定到这一版本。

python -m pip install frida psutil

标准明文 SQLite 数据库可直接读取，仅需 Node.js。

02全局安装 CLI

在 PowerShell 运行。安装完成后，可在任意目录使用 qq-cli。

npm install --global qq-cli-local
qq-cli --help

也可从 GitHub Releases 下载 .tgz 包，运行 npm install --global .\下载的包.tgz 安装。

03连接本地消息库

将示例路径和数字替换为你自己的 Msg3.0.db 路径与 QQ 账号 UIN，再导入数据库。

qq-cli init --db "D:\QQ-data\123456789\Msg3.0.db" --account-uin 123456789
qq-cli refresh
qq-cli status --format text

配置、查询缓存和检查点保存在 %LOCALAPPDATA%\qq-cli。之后运行 qq-cli refresh 更新查询缓存。

常用命令

EVERYDAY COMMANDS

下方群号为示例，请替换为实际群号。默认输出 JSON，添加 --format text 可切换为文本。

查看最近的会话

qq-cli sessions --limit 10 --format text

查看群聊最近 7 天的消息

qq-cli history group:1234567890 --days 7 --limit 20 --format text

搜索指定会话中的关键词

qq-cli search "关键词" --chat group:1234567890 --days 30 --format text

导出 Markdown 聊天记录

qq-cli export group:1234567890 --days 7 --format markdown --output ".\chat.md"

使用范围

BEFORE YOU START

从本地记录获取信息

contacts 和 members 展示消息库中观察到的对象与发言者。unread 和 new-messages 根据本工具保存的检查点计算变化。

summarize 生成本地消息素材和引用，供后续总结使用。

Classic PCQQ 适配

加密数据库支持上述指定版本的 Classic PCQQ x86；QQNT 尚未适配。

工具读取源数据库，在临时副本上处理加密库。完整实现说明见仓库 DESIGN.md。
